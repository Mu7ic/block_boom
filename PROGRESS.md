# Блок Бум! — что сделано и что дальше

> Файл-памятка для продолжения работы на другом компьютере (в том числе для Claude).
> Начни с этого файла, потом читай `README.md` (запуск и выкладка на VPS).
> Состояние на 24.11.2026.

## Что это

Мини-игра «блоки 8×8» для конкурса. **Вся игра — один файл `index.html`** (~2180 строк):
звуки, музыка, иконка, PWA-манифест и стили генерируются кодом, внешних файлов нет.
Папка `server/` — Node.js-сервер (только пакет `ws`) для онлайн-боя.

## Что уже сделано

### Игра (`index.html`)
- **Режимы:** Классика, Аркада (30 уровней с фруктами и камнями), Против бота (3 мин),
  Онлайн-бой (с другом по коду комнаты).
- **Генерация фигур** (`smartSet`, `bestMove`, `findJackpot`, ~стр. 946–1107):
  80% «умных» слотов (`ASSIST = 0.8`), всегда выдаются фигуры, которые влезают; есть «джекпоты» на большие очистки.
- **Бот** (~стр. 1516): думает 1.7–3.2 с, ошибается с шансом 15% (`BOT_MISTAKE`).
- **20 скинов** блоков (`SKINS`, ~стр. 657): классика, диско, арбузики, яичница, неон, желе, глазастики,
  лёд, золото, пиксели, аквариум, пончики, печеньки, дерево, космос, пузыри, сердечки, матрица, пицца и др.
  Многие анимированы. Есть экран коллекции и отметка «новинка».
- **Звук:** SFX и музыка на WebAudio (пентатоника `PENTA`), вибрация, переключатели в меню.
- **Обучение** (`TUT`) при первом запуске + одноразовые подсказки `hintOnce`.
- **Эффекты:** частицы, тряска, летящие фрукты, всплывающий текст, анимация проигрыша.
- **Сохранения** в `localStorage` (ключи `bp-*`, рекорд — `blockpuzzle-best`).
- **PWA:** манифест через data-URL (установка на телефон работает только по HTTPS).

### Онлайн (`server/server.js`, ~170 строк)
- Отдаёт `index.html` (читает файл заново при каждом запросе) и `/health`.
- WebSocket `/ws`: комнаты на двоих с кодом из 4 цифр, ссылка `#join=1234`,
  отсчёт 3-2-1, общий таймер 3 мин, итог объявляет сервер, реванш, победа при выходе соперника.
- Сообщения: `create`, `join`, `state`, `rematch`, `leave`.
- Тест коротких боёв: `DURATION_MS=15000 npm start`.

### Выкладка
- `deploy/blockboom.service` (systemd) и `deploy/nginx-blockboom.conf` — готовы, инструкция в `README.md`.
- `.claude/launch.json` — превью в Claude Code (`node server/server.js`, порт 8765).

## Что ещё НЕ сделано / важно помнить

- [ ] **Git: ни одного коммита.** Файлы только добавлены в индекс. Чтобы забрать проект домой —
      закоммитить и запушить на GitHub (или просто скопировать папку, без `node_modules`).
- [ ] **`ONLINE_SERVER` пустой** (`index.html`, ~стр. 1718). Перед сдачей на конкурс вписать
      `wss://ДОМЕН/ws`, иначе из файла онлайн-бой не заработает.
- [ ] **VPS ещё не настроен** (домен, nginx, certbot) — шаги в `README.md`.
- [ ] В `deploy/nginx-blockboom.conf` заменить `ИМЯ_ДОМЕНА`.

## Идеи, что улучшать (предложения, приоритет обсудить)

1. **Онлайн:** проверка очков на сервере (сейчас очки считает клиент — можно подделать);
   переподключение при обрыве связи; поиск случайного соперника, а не только по коду.
2. **Баланс:** подстроить `ASSIST`, `CANDIDATES`, сложность бота и уровней Аркады по отзывам тестеров.
3. **Мобильные:** проверить на разных телефонах (маленькие экраны, iOS Safari: звук и вибрация).
4. **Контент:** больше уровней Аркады, ежедневное задание, достижения, новые скины.
5. **Код:** `index.html` большой — при необходимости разбить на модули для разработки
   и собирать обратно в один файл для конкурса.
6. **Офлайн:** service worker, чтобы установленная игра работала без сети.

## Как быстро продолжить дома

```
cd server
npm install
npm start
```
Открыть http://localhost:8765. Дальше — выбрать пункт из списков выше.
