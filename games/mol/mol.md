# «Моль в шкафу» — пояснительная записка

**Файл:** `games/mol/index.html` · мини-игра для программы лояльности «Пуговки»

## 1. Идея и правила

Открытый шкаф: три полки со стопками сложенной одежды, на каждой стопке пуговка (всего 9).
Из тёмных складок между вещами вылезает моль и летит к ближайшей пуговке. Нужно тапнуть по
моли, пока она её не съела. Села на пуговку — вокруг бежит красное кольцо, не успел — пуговку
съели (−30 очков), на её месте остаются обрывки ниток. Задел пуговку пальцем — −15. Промах
мимо всего — серия сначала.

Моль бывает разная: **обычная** (10 очков), **быстрая** жёлтая, петляет (20), **толстая** —
нужно два тапа (5 + 30), **стайка** из 3–4 маленьких (по 6, вся стайка ещё +20). Поймал моль,
пока она вылезает из складки, — ещё +5. Точные тапы подряд дают множитель: каждые 6 — +1,
до ×5. Со временем моль вылезает чаще и летает быстрее. Раз в 12 секунд одна съеденная
пуговка пришивается обратно, а в конце каждая целая — +15.

Порядок появления моли — «набор дня» из даты, одинаковый для всех игроков в этот день.

## 2. Сессия и аудитория

- **Сессия:** 75 секунд, время идёт с первого касания. С итогом — около 1,5 минуты.
- **Аудитория:** все участники программы. Знакомая бытовая ситуация, управление одним
  касанием. При первом запуске игра сразу открывает забег, и рука показывает на моль.
- **Устройство:** телефон. Поле одинаковых пропорций на любом экране (сложность не зависит
  от размера), каждый палец — отдельное касание. Свернули вкладку — время стоит.
  Один HTML-файл без внешних запросов.

## 3. Вход и награды

| | |
|---|---|
| Бесплатно | 1 забег в день; 3 дня подряд — 2 в день |
| Платно | 10 пуговок |
| Задание дня | одно на всех, проверяется по итогам забега: +5 пуговок |
| Награда за очки | 800 → 2 · 1800 → 5 · 3200 → 8 · 4800 → 12 · 6800 → 16 |
| Лимит | 60 пуговок в сутки (забеги + задание дня) |
| Траты | 4 цвета шкафа по 10 пуговок, только внешний вид |

Награда зависит **только от очков**. Все цены и пороги — на экране «Правила и награды».

## 4. Экономика

**Допущения.** Пуговка — единица баллов программы. Распределение игроков 30/40/20/10%
(новичок / средний / хороший / сильный).

**Симуляция** на настоящем коде игры (кусок логики из `index.html` запускается в node):
по 400 забегов на тип игрока на 30 разных «днях». Игрок замечает моль с задержкой, тапает
с ошибкой, которая растёт со скоростью моли, и выбирает самую срочную (ту, что уже ест).
Медиана очков: новичок ~1000, средний ~1890, хороший ~3650, сильный ~6350. Новичок теряет
почти все пуговки, хороший — почти ни одной. Средняя выплата за забег: 1,8 / 3,8 / 7,7 / 13,1
→ **≈ 4,9 пуговки**. Первая версия оказалась лёгкой (≈8 за вход): моль стала вылезать чаще,
пороги подняли.

Проверили и «спам»: случайные тапы по 10 в секунду дают ~420 очков (меньше первого порога),
даже 20 в секунду — в среднем 0,4 пуговки. Тапать наугад невыгодно из-за штрафа за пуговки.

| Сценарий игрока за день | Итог для программы |
|---|---|
| Только бесплатный забег | −4,9 (цена удержания) |
| 1 бесплатный + 1 платный | **+0,2** |
| 1 бесплатный + 3 платных | **+10,4** |
| Покупка шкафа | **+10** |

Платный забег в среднем сжигает ≈5,1 пуговки. Бесплатные забеги — расход на удержание,
ограниченный лимитом 60 в сутки. Параметры собраны в объекте `ECON`.

**Риски:** сильные игроки зарабатывают ≈13 за вход 10 (ограничено лимитом); очки считаются
в браузере (в продакшене нужна проверка на сервере); модель игрока в симуляции условная —
пороги нужно проверить на живых тестерах; мелкая моль из стайки на маленьком экране может
быть трудной для пальца (зона касания у неё больше рисунка).

## 5. Как использовали ИИ

Код, графика на canvas, звук, подбор сложности и порогов симуляцией и этот текст сделаны
вместе с ИИ-ассистентом Claude (Anthropic) в Claude Code. Автор выбрал идею, принимал решения
по механике и балансу, проверял игру. Стиль — по брендбуку «Пуговок», шрифт Onest (SIL OFL).
