# «Пришей пуговку» — пояснительная записка

**Файл:** `games/prishey-pugovku/index.html` · мини-игра для программы лояльности «Пуговки»

## 1. Идея и правила

Игла качается над большой пуговицей. Нужно коснуться экрана, когда она над **светящейся
дырочкой**. Попадание в центр — «точно», 30 очков, по краю — 10, мимо — −2 секунды и серия
сначала. Каждые 5 попаданий подряд увеличивают множитель (до ×5).

4 стежка крестиком пришивают пуговицу: +50 очков, без промахов ещё +50. Пуговица уезжает на
планку рубашки, следующая качается быстрее и с меньшими дырочками. С 6-й пуговицы игла ещё
и покачивается вверх-вниз, подсказка — тень иглы на ткани.

## 2. Сессия и аудитория

- **Сессия:** 90 секунд, время идёт с первого касания. С итогом — около 2 минут.
- **Аудитория:** все участники программы. Управление одним касанием, понятно за 5 секунд:
  при первом запуске игра сразу открывает забег, и рука показывает, куда нажать.
- **Устройство:** телефон. Один HTML-файл без внешних запросов.

## 3. Вход и награды

| | |
|---|---|
| Бесплатно | 1 забег в день; 3 дня подряд — 2 в день |
| Платно | 10 пуговок, списываются при первом касании |
| Сдельная оплата | пуговица без промахов — 1,5 · с промахом — 0,25 · не дошита — 0 |
| Задание дня | одно на всех, проверяется по итогам забега: +5 пуговок |
| Лимит | 20 за забег, 60 в сутки (забеги + задание дня) |
| Траты | 5 цветных ниток по 10 пуговок, только внешний вид |

**Модель «сдельная оплата ателье».** Платят за каждую пришитую пуговицу (4 стежка), а за чистую
работу без единого промаха — в 6 раз больше. Так главное умение игры — попадать без промахов —
напрямую превращается в заработок, а «просто дотыкать» почти ничего не приносит. Начатая, но
не пришитая пуговица не оплачивается.

Дробные части (0,25; 1,5) копятся весь забег, в конце сумма **округляется вниз** — и это видно
честно: «3,25 → 3». Связь «действие → пуговки» видна сразу: над полем цена текущей пуговицы
(после промаха «~~1,5~~ 0,25»), пришитая пуговица уезжает на планку рубашки, под ней подписано
«+1,5» или «+0,25», в шапке растёт «Заработок». Итог — разбивка «пришиты без промахов: 2 × 1,5 = 3»,
округление, лимит и подсказка «ещё одна пуговица без промахов — +1». Очки остались для рекорда.
Все цены — на экране «Правила и награды» из `ECON`.

## 4. Экономика

**Допущения.** Пуговка — единица баллов программы. Распределение игроков 30/40/20/10%
(новичок / средний / хороший / сильный).

**Симуляция** использует настоящие функции игры (`levelParams`, `judge`, `rewardOf`): игла качается,
игрок касается с ошибкой по времени (80 → 22 мс), иногда «зевает». По 600 забегов на тип;
медианы очков (~710 / 1040 / 1560 / 3200) совпадают с прошлой версией модели.

| | Новичок | Средний | Хороший | Сильный |
|---|---|---|---|---|
| Пришито пуговиц | 5,4 | 7,2 | 8,8 | 11,2 |
| Из них без промахов | 0,6 | 1,8 | 4,0 | 7,9 |
| Средняя выплата | 1,8 | 3,7 | 6,8 | 12,3 |

Средняя выплата за вход — **≈ 4,6 пуговки**, лучший забег сильного — 19.
**Спам и случайные касания** дают 0: каждый промах стоит 2 секунды, за забег набирается
меньше одной пуговицы с промахами.

| Сценарий игрока за день | Итог для программы |
|---|---|
| Только бесплатный забег | −4,6 (цена удержания) |
| 1 бесплатный + 1 платный | **+0,8** |
| 1 бесплатный + 3 платных | **+11,6** |
| Покупка нитки | **+10** |

**Риски:** сильные игроки получают ≈12 за вход 10 (ограничено лимитами); оплата считается
в браузере (нужна проверка на сервере); курс 1,5 / 0,25 и модель игрока стоит проверить
на живых тестерах — дроби могут показаться непривычными.
