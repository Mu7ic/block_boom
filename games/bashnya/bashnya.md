# «Пуговичная башня» — пояснительная записка

**Файл:** `games/bashnya/index.html` · мини-игра для программы лояльности «Пуговки»

## 1. Идея и правила

Пуговица качается на нитке над башней. Касание обрезает нитку — пуговица падает на вершину.
Игра на **равновесие**: пуговица держится, если её центр (и центр тяжести всего, что выше)
приходится на опору. Иначе верх башни падает — минус одна из 3 ниток 🧵.

- **Сшивание:** каждые 5 устоявших пуговиц прошиваются (+50) — их уже не уронить.
- Пуговица — 10 очков; почти точно по центру — ещё 20 × серия точных (до ×3), ровно — ещё 5.
- Нитка качается всё быстрее, пуговицы становятся меньше. Размеры и цвета — **набор дня**.

Механика своя: ничего не «обрезается» — всё решают равновесие и сшивание.

## 2. Сессия и аудитория

- **Сессия:** 90 секунд или пока не кончатся 3 нитки; новичок в среднем ставит ~24 пуговицы.
- **Аудитория:** все участники программы; одно касание, понятно сразу — рука в первом
  забеге показывает, куда нажать.
- **Устройство:** телефон. Один HTML-файл без внешних запросов.

## 3. Вход и награды

| | |
|---|---|
| Бесплатно | 1 забег в день; 3 дня подряд — 2 в день |
| Платно | 10 пуговок, списываются при первом касании (вышел раньше — не списано) |
| Награда — за высоту | каждый шов: на высоте 5–15 — 0, 20–35 — по 1, с 40 — по 2 |
| Задание дня | одно на всех: +5 пуговок |
| Лимит | 60 пуговок в сутки (забеги + задание дня) |
| Траты | 4 основания по 10 (игольница, напёрсток, шкатулка, книга) — ширина у всех одна |

**Модель «награда за высоту».** Каждые 5 устоявших пуговиц сшиваются, и шов платит по своей
высоте — чем выше, тем дороже. Шов уже не упадёт, поэтому заработанное не сгорает: риск —
только за то, что выше последнего шва. У правого края поля — **линейка**: деление на каждой
пуговице, у каждого шва его цена (пройденные — «✓»), а следующая платная высота отмечена
пунктиром через всё поле — видно, докуда тянуть башню. Поле «Награда» показывает заработанное;
при сшивании всплывает «+1». На итоге — разбивка («швы на высоте 20–35 · 4 × 1 = 4»), лимит
и подсказка («следующий шов — на высоте 50: +2»). Очки и точные укладки — для рекорда.
Расчёт — одна функция `rewardOf()` для игры, линейки и симуляции.

Предложенную шкалу 1, 1, 2, 2, 3, 3… проверили: швов у игроков 4–11, и при ней новичок
получал ~5, а средняя выплата ~8. Поэтому первые три шва (до высоты 15) бесплатны,
а цена растёт медленнее.

## 4. Экономика

**Допущения:** игроки 30/40/20/10%; ошибка момента касания 85 / 60 / 45 / 33 мс; реакция
после приземления 0,55 / 0,45 / 0,38 / 0,32 с; падение пуговицы 0,5 с, кувырок упавшего
верха 1,1 с.

**Симуляция** (настоящие `newState/place/rewardOf`, 400 забегов на тип × 3 набора дня): швов
4,7 / 6,6 / 8,6 / 10,7; нитки кончаются у 84 / 70 / 51 / 16%. Выплата **1,9 / 4,2 / 7,4 / 11,4**
→ **≈ 4,9 за вход 10**. У новичка медиана 1, ноль — в 32% забегов. Максимум в симуляции — 14
(и у почти идеального игрока), 14 швов дали бы 18.

**Спам не выгоден:** касания «не глядя», сразу после приземления, дают 0 — башня падает
раньше первого платного шва.

| Сценарий игрока за день | Итог для программы |
|---|---|
| Только бесплатный забег | −4,9 |
| 1 бесплатный + 1 платный | **+0,3** |
| 1 бесплатный + 3 платных | **+10,6** |
| Покупка основания | **+10** |

**Риски:** сильный получает ~11 за вход (ограничено лимитом); треть новичков уходит без
пуговок — смягчает задание дня, но стоит проверить на тестерах; счёт в браузере — в продакшене
нужна проверка на сервере; упавшая башня может раздражать — падает только несшитая часть.

## 5. Как использовали ИИ

Код, расчёт равновесия, графика, симуляция и подбор порогов, а также этот текст сделаны
вместе с ИИ-ассистентом Claude (Anthropic) в Claude Code. Автор выбрал идею, принимал решения
по механике и экономике, проверял игру. Стиль — по брендбуку «Пуговок», шрифт Onest (SIL OFL).
