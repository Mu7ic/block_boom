# «Пуговичная башня» — пояснительная записка

**Файл:** `games/bashnya/index.html` · мини-игра для программы лояльности «Пуговки»

## 1. Идея и правила

Пуговица качается на нитке над башней. Касание обрезает нитку — пуговица падает на вершину.
Игра на **равновесие**: пуговица держится, если её центр (и центр тяжести всего, что выше)
приходится на опору. Иначе верх башни падает — минус одна из 3 ниток 🧵.

- **Сшивание:** каждые 5 устоявших пуговиц прошиваются (+50) — их уже не уронить.
- Пуговица — 10 очков; почти точно по центру — ещё 20 × серия точных (до ×3), ровно — ещё 5.
- Нитка качается всё быстрее, пуговицы становятся меньше. Размеры и цвета — **набор дня**.

Механика своя: ничего не «обрезается» — всё решают равновесие и сшивание.

## 2. Сессия и аудитория

- **Сессия:** 90 секунд или пока не кончатся 3 нитки; новичок в среднем ставит ~24 пуговицы.
- **Аудитория:** все участники программы; одно касание, понятно сразу — рука в первом
  забеге показывает, куда нажать.
- **Устройство:** телефон. Один HTML-файл без внешних запросов.

## 3. Вход и награды

| | |
|---|---|
| Бесплатно | 1 забег в день; 3 дня подряд — 2 в день |
| Платно | 10 пуговок |
| Задание дня | одно на всех, проверяется по итогам забега: +5 пуговок |
| Награда за очки | 550 → 2 · 950 → 5 · 1500 → 8 · 2000 → 12 · 2400 → 16 |
| Лимит | 60 пуговок в сутки (забеги + задание дня) |
| Траты | 4 основания башни по 10 (игольница, напёрсток, шкатулка, книга) — ширина у всех одна |

## 4. Экономика

**Допущения:** игроки 30/40/20/10%; ошибка момента касания 90 / 60 / 40 / 25 мс; падение
пуговицы ~0,55 с.

**Симуляция** (на функции равновесия из игры, 300–400 забегов на тип): медиана очков
~585 / ~1000 / ~1600 / ~2100; новичок обычно теряет все нитки, сильный — почти никогда.
Выплата 1,8 / 4,1 / 7,1 / 11,2 → **≈ 4,7 пуговки**.

| Сценарий игрока за день | Итог для программы |
|---|---|
| Только бесплатный забег | −4,7 |
| 1 бесплатный + 1 платный | **+0,6** |
| 1 бесплатный + 3 платных | **+11** |
| Покупка основания | **+10** |

**Риски:** сильные игроки получают ≈11 за вход 10 (ограничено лимитом); очки считаются
в браузере (в продакшене — проверка на сервере); упавшая башня может раздражать — поэтому
падает только неустойчивая часть, а сшитая остаётся.
