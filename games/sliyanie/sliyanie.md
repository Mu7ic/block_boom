# «Пуговичное слияние» — пояснительная записка

**Файл:** `games/sliyanie/index.html` · мини-игра для программы лояльности «Пуговки»

## 1. Идея и правила

Поле 5×5 — шкатулка с пуговицами. Перетащи пуговицу на **такую же в любом месте поля**
(или коснись одной, потом другой) — они сольются в следующую:
крошка → мятная → голубая → фиалка → алая → **золотая 👑**.

- Слияние в уровень L приносит 5·2^L очков (20…320). Золотая — ещё +300, она уходит
  в копилку и освобождает место.
- Слияния с паузой не больше 1,3 секунды — серия, до ×3.
- Новые пуговицы падают в пустые клетки всё чаще (раз в 1,0 → 0,5 с). Нет места — пуговица
  не падает, серия сбрасывается. Забег не заканчивается досрочно.
- Уровни и места падения — **набор дня**.

Механика своя: не «сдвигание» как в 2048 и не падение с физикой — свободное слияние
по всему полю под нарастающим потоком.

## 2. Сессия и аудитория

- **Сессия:** 90 секунд с первого касания.
- **Аудитория:** любители спокойных «склеек» и тех, кто любит скорость; при выборе пуговицы
  такие же подсвечиваются — подсказка для новичка. Рука в первом забеге показывает жест.
- **Устройство:** телефон. Один HTML-файл без внешних запросов.

## 3. Вход и награды

| | |
|---|---|
| Бесплатно | 1 забег в день; 3 дня подряд — 2 в день |
| Платно | 10 пуговок |
| Награда за очки | 3500 → 2 · 6000 → 5 · 10000 → 8 · 14500 → 12 · 18500 → 16 |
| Лимит | 60 пуговок в сутки |
| Траты | 4 ткани шкатулки по 10 (лён, мята, деним, бархат) |

## 4. Экономика

**Допущения:** игроки 30/40/20/10%; на одно слияние у игрока уходит 1,6 / 1,2 / 0,9 / 0,7 с;
игрок сливает самую старшую доступную пару.

**Симуляция** (на настоящих функциях игры, 400 забегов на тип): медиана очков
~3700 / ~5700 / ~13800 / ~17100. Выплата 1,9 / 3,0 / 9,5 / 12,1 → **≈ 4,9 пуговки**.

Первая версия была несправедливой: новичок почти всегда переполнял шкатулку и вылетал,
а средний и сильный набирали одинаково — их сдерживал поток пуговиц, а не умение. Конец
по переполнению убран, поток ускорен, окно серии сужено — теперь счёт растёт с умением.

| Сценарий игрока за день | Итог для программы |
|---|---|
| Только бесплатный забег | −4,9 |
| 1 бесплатный + 1 платный | **+0,2** |
| 1 бесплатный + 3 платных | **+10,4** |
| Покупка ткани | **+10** |

**Риски:** быстрые игроки получают ≈12 за вход 10 (ограничено лимитом); разрыв между средним
и хорошим игроком большой — пороги стоит проверить на живых тестерах; очки считаются
в браузере (в продакшене — проверка на сервере).

## 5. Как использовали ИИ

Код, логика слияний, симуляция с моделью игрока и подбор порогов, а также этот текст сделаны
вместе с ИИ-ассистентом Claude (Anthropic) в Claude Code. Автор выбрал идею, принимал решения
по механике и экономике, проверял игру. Стиль — по брендбуку «Пуговок», шрифт Onest (SIL OFL).
