# «Пуговичное слияние» — пояснительная записка

**Файл:** `games/sliyanie/index.html` · мини-игра для программы лояльности «Пуговки»

## 1. Идея и правила

Поле 5×5 — шкатулка с пуговицами. Перетащи пуговицу на **такую же в любом месте поля**
(или коснись одной, потом другой) — они сольются в следующую:
крошка → мятная → голубая → фиалка → алая → **золотая 👑**.

- Слияние в уровень L приносит 5·2^L очков (20…320). Золотая — ещё +300, она уходит
  в копилку и освобождает место.
- Слияния с паузой не больше 1,3 секунды — серия, до ×3.
- Новые пуговицы падают в пустые клетки всё чаще (раз в 1,0 → 0,5 с). Нет места — пуговица
  не падает, серия сбрасывается. Забег не заканчивается досрочно.
- Уровни и места падения — **набор дня**.

Механика своя: не «сдвигание» как в 2048 и не падение с физикой — свободное слияние
по всему полю под нарастающим потоком.

## 2. Сессия и аудитория

- **Сессия:** 90 секунд с первого касания.
- **Аудитория:** любители спокойных «склеек» и тех, кто любит скорость; при выборе пуговицы
  такие же подсвечиваются — подсказка для новичка. Рука в первом забеге показывает жест.
- **Устройство:** телефон. Один HTML-файл без внешних запросов.

## 3. Вход и награды

| | |
|---|---|
| Бесплатно | 1 забег в день; 3 дня подряд — 2 в день |
| Платно | 10 пуговок, списываются при первом касании (вышел раньше — не списано) |
| Награда — за цель | золотые 👑: 1-я — 1, 2-я — 2, 3-я — 3, 4-я и дальше — по 6 |
| Задание дня | одно на всех: +5 пуговок |
| Лимит | 60 пуговок в сутки (забеги + задание дня) |
| Траты | 4 ткани шкатулки по 10 |

**Модель «награда за цель».** Цель видна сразу — довести пуговицы до золотой. Платят только
за золотые, каждая следующая дороже: три золотые = 1 + 2 + 3 = 6. Очки остаются для рекорда.
В игре поле «Награда» показывает заработанное, над золотой всплывает «+N». На итоге — разбивка
по строкам, предупреждение о лимите и подсказка («ещё одна золотая — ещё +6»). Расчёт — одна
функция `rewardOf()` для игры и симуляции.

**Почему цена растёт.** Золотых за 90 секунд выходит 1–5, и их число слабо зависит от умения:
новичок собирает 1–2, сильный 4. При цене «3–4 за каждую» новичок получал бы половину выплаты
сильного, а средняя ушла бы выше входа. Плату за алую тоже проверили и отказались: первая
золотая тогда ничего бы не прибавляла, а без золотой остаются лишь очень медленные игроки
(1% забегов при 2,2 с на слияние).

## 4. Экономика

**Допущения:** игроки 30/40/20/10%; на слияние уходит 1,6 / 1,2 / 0,9 / 0,7 с; самую старшую
пару выбирают в 30 / 60 / 85 / 95% случаев, иначе — случайную.

**Симуляция** (настоящие `newState/tick/merge/rewardOf`, 200 забегов на тип × 5 наборов дня):
золотых 1,8 / 2,2 / 3,2 / 4,0; выплата **2,6 / 3,6 / 6,9 / 12,0** → **≈ 4,8 за вход 10**.
Максимум — 18 (5 золотых); «робот» с 0,3 с на слияние получает в среднем 14,3.

**Спам не выгоден:** случайные тапы (4 в секунду) дают 0,17 за забег — платят за итог,
а не за действия.

| Сценарий игрока за день | Итог для программы |
|---|---|
| Только бесплатный забег | −4,8 |
| 1 бесплатный + 1 платный | **+0,4** |
| 1 бесплатный + 3 платных | **+10,8** |
| Покупка ткани | **+10** |

**Риски:** сильный получает ~12 за вход (ограничено лимитом); награда ступенчатая — порог
между 2 и 3 золотыми стоит проверить на тестерах; наборы дней немного различаются (4,4–5,1); счёт
в браузере — в продакшене нужна проверка на сервере.
