# «Пуговичный щелчок» — пояснительная записка

**Файл:** `games/shchelchok/index.html` · мини-игра для программы лояльности «Пуговки»

## 1. Идея и правила

Настольная игра «на щелчок»: тянешь пуговицу назад, как из рогатки, и отпускаешь.
Она скользит по столу с трением, отскакивает от бортов и катушек. Очки зависят от того,
где пуговица остановилась: центр мишени 100, среднее кольцо 50, внешнее 20.

- Попадания подряд — множитель ×1,5 … ×3.
- **Рикошет:** отскок и всё равно попадание в 50 или 100 — ещё +25.
- 10 щелчков. Мишень с каждым дальше и меньше, появляются катушки, с 7-го щелчка одна стоит
  прямо на пути.
- На первых двух щелчках виден пунктир траектории — обучение, одинаковое для всех.

**Трасса дня:** расстановка мишеней и катушек задаётся датой и одинакова для всех игроков.
Стол всегда одних пропорций, поэтому физика одинакова на любом телефоне.

## 2. Сессия и аудитория

- **Сессия:** 10 щелчков, ~1–1,5 минуты.
- **Аудитория:** все участники программы, особенно любители «физических» казуалок.
  Жест «оттяни и отпусти» знаком всем, при первом запуске его показывает рука.
- **Устройство:** телефон. Один HTML-файл без внешних запросов.

## 3. Вход и награды

| | |
|---|---|
| Бесплатно | 1 забег в день; 3 дня подряд — 2 в день |
| Платно | 10 пуговок, списываются при первом щелчке (вышел раньше — не списано) |
| Плата за попадание | с 3-го щелчка: яблочко +2, среднее кольцо +1, внешнее 0 |
| Рекорд дня | +2, один раз в день: со 2-го забега побил свой лучший счёт дня, счёт ≥ 1000 |
| Задание дня | одно на всех: +5 пуговок |
| Лимит | 60 пуговок в сутки |
| Траты | 4 пуговицы для щелчков по 10, только внешний вид |

**Модель «плата за попадание + рекорд».** Каждый щелчок оплачивается по зоне, где остановилась
пуговица. Первые два щелчка с пунктиром — пристрелка без оплаты: там попадает почти каждый.
Множитель серии и рикошеты влияют на очки и рекорд, но не на плату. Во всплывающей надписи
у мишени видно «+2», поле «Награда» копит заработанное. На итоге — разбивка («яблочко · 4 × 2
= 8», «рекорд дня (было 885) — 2»), лимит и подсказка: «побей сегодняшний лучший счёт — ещё
+2» или цены зон. Расчёт — одна функция `rewardOf()` для игры и симуляции.

## 4. Экономика

**Допущения:** игроки 30/40/20/10%; ошибка угла 0,10 / 0,07 / 0,048 / 0,032 рад, силы
22 / 15 / 10 / 7%; на щелчках с пунктиром ошибка втрое меньше. Для каждого щелчка
трассы перебором угла и силы найден устойчивый лучший удар.

**Симуляция** (настоящие `makeCourse/step/zoneOf/rewardOf`, 3 трассы × 400 дней на тип, в дне
бесплатный + 2 платных забега): медиана очков ~510 / ~790 / ~1225 / ~1660. За попадания
**2,7 / 4,4 / 6,8 / 9,1** → **≈ 4,8 за забег**, максимум 16 (+2 рекорд = 18).

**Бонус рекорда и средний возврат.** Бонус получают в 6 / 38 / 66 / 68% дней. Выплата
по номеру забега: 1-й 4,9, 2-й 5,3, 3-й 5,0 — **≈ 5,2 на платный вход**. С порогом 800
было бы 5,3, поэтому порог 1000. «Фарм» не выгоден: слить первый забег ради бонуса во втором —
2,7–10,9 за два забега против 5,3–19,0 при честной игре. Случайные щелчки дают 0,08.

| Сценарий игрока за день | Итог для программы |
|---|---|
| Только бесплатный забег | −4,9 |
| 1 бесплатный + 1 платный | **−0,2** |
| 1 бесплатный + 3 платных | **+9,9** |
| Покупка пуговицы | **+10** |

**Риски:** разброс уже, чем хотелось (новичок 2,7, сильный 9) — в кольца попадают все;
бонус рекорда чуть поднимает выплату (5,2), можно снизить до +1. Стол всегда 1 : 1,62 —
физика одна на любом телефоне. Счёт в браузере — в продакшене проверка на сервере.

## 5. Как использовали ИИ

Код, физика, графика, симуляция «лучшего удара» и подбор порогов, а также этот текст сделаны
вместе с ИИ-ассистентом Claude (Anthropic) в Claude Code. Автор выбрал идею, принимал решения
по сложности и экономике и проверял игру. Стиль — по брендбуку «Пуговок», шрифт Onest (SIL OFL).
