# «Шкатулка» — пояснительная записка

**Файл:** `games/shkatulka/index.html` · мини-игра для программы лояльности «Пуговки»

## 1. Идея и правила

Сортировка пуговиц на скорость. Пуговицы появляются по одной (видно ещё 3 следующих),
нужно коснуться баночки, куда её положить. Правило меняется по ходу забега:

1. по **цвету** — 2, потом 3 и 4 баночки;
2. по **размеру** — большие и маленькие;
3. по цвету, но баночки переставлены;
4. по **числу дырочек** — 2 или 4;
5. дальше правило меняется каждые 8 пуговиц.

Смену правила показывает мигающая плашка «Новое правило!». Верный ответ — 10 очков и до 10
за скорость; каждые 8 верных подряд увеличивают множитель (до ×4). Ошибка — −2 секунды.
**Набор дня** (порядок пуговиц и баночек) одинаков для всех.

**Доступность:** у каждого цвета свой значок (● ▲ ■ ★) на пуговице и на баночке — сортировать можно и тем, кто плохо различает цвета.

## 2. Сессия и аудитория

- **Сессия:** 60 секунд, время идёт с первого ответа.
- **Аудитория:** все участники программы; тренирует внимание, понятна без текста — рука
  при первом запуске показывает нужную баночку. На ПК можно нажимать клавиши 1–4.
- **Устройство:** телефон. Один HTML-файл без внешних запросов.

## 3. Вход и награды

| | |
|---|---|
| Бесплатно | 1 забег в день; 3 дня подряд — 2 в день |
| Платно | 10 пуговок, списываются при первом ответе (вышел до него — ничего не списано) |
| Награда за забег | каждая верная пуговица засчитывается по серии ×1…×4, быстрый ответ — ещё +1; каждые **28** засчитанных = 1 пуговка |
| Наборы коллекции | 🌈 по 25 каждого цвета → +2 · 📏 50 больших и 50 маленьких → +3 · 🕳 50 с 2 и 50 с 4 дырочками → +3 · 👑 по 100 каждого цвета → +10 (разово) |
| Задание дня | одно на всех, проверяется по итогам забега: +5 пуговок |
| Лимит | 60 пуговок в сутки (забеги, наборы и задание дня) |
| Траты | 4 стиля баночек по 10 (жесть, дерево, керамика, золото) |

**Награда привязана к механике.** Платят за разложенные пуговицы, а серия без ошибок
(тот же множитель, что у очков) засчитывает каждую вдвое-вчетверо — аккуратность выгоднее
спешки. Во время забега рядом со счётом видно «+N» заработанных пуговок.

**Коллекция.** Каждая разложенная пуговица остаётся в личной шкатулке между забегами.
Меню показывает прогресс четырёх наборов и сколько чего не хватает («● 3 · ★ 7»).
За собранный набор — разовый бонус. Три первых набора закрываются за 1–4 дня, «Полная
шкатулка» — за 4–7 дней: повод вернуться завтра. «Сбросить демо» обнуляет коллекцию.

**Итог** — разбивка «за что заплачено» (забег, собранные наборы, дневной лимит) и одна
подсказка: сколько ещё до следующей пуговки или до ближайшего набора.

## 4. Экономика

**Допущения:** игроки 30/40/20/10%; время реакции 1,15 / 0,9 / 0,72 / 0,58 с; ошибки
7 / 5 / 3,5 / 2%, сразу после смены правила — на 0,55 с медленнее и ошибок втрое больше.

**Симуляция** в node на настоящих функциях игры (`makeSet`, `creditOf`, `rewardOf`):
300 игроков каждого типа × 7 дней × 2 забега, наборы дня разные. Разложено за забег
~36 / ~47 / ~60 / ~78 пуговиц.

| Игрок | За забег | Наборы (на вход, 7 дней) | Всего |
|---|---|---|---|
| Новичок | 1,6 | +0,6 | **2,2** |
| Средний | 3,2 | +0,8 | **4,0** |
| Хороший | 5,5 | +1,3 | **6,8** |
| Сильный | 9,0 | +1,3 | **10,3** |

**Средняя выплата за вход ≈ 4,65 пуговки** (3,8 за забег + 0,9 наборы). Максимум
за один забег — 13 (+ бонус набора). Средний игрок собирает «Полную шкатулку»
за неделю в 1 случае из 3. «Спам» (случайная баночка каждые 0,15 с) даёт 0,7 —
ошибка стоит 2 секунды и сбрасывает серию.

| Сценарий игрока за день | Итог для программы |
|---|---|
| Только бесплатный забег | −4,65 (цена удержания) |
| 1 бесплатный + 1 платный | **+0,7** |
| 1 бесплатный + 3 платных | **+11** |
| Покупка стиля баночек | **+10** |

Когда все наборы собраны, остаётся только оплата за забег (≈3,8) — коллекция работает
как бонус первой недели.

**Риски:** сильные игроки получают ≈10 за вход 10 (ограничено лимитом); бонус набора
«сгорает», если дневной лимит уже набран; всё считается в браузере (в продакшене —
проверка на сервере); набор дня можно выучить, но в нём 200 пуговиц и 7+ смен правил.
