# «Ниточка» — пояснительная записка

**Файл:** `games/nitochka/index.html` · мини-игра для программы лояльности «Пуговки»

## 1. Идея и правила

На ткани в клетку лежат пары пуговок одного цвета. Пальцем ведёшь нитку по клеткам от пуговки
к такой же. Нитки разных цветов не пересекаются: новая нитка перерезает старую.

**Свой поворот — пуговица-переход.** Белая пуговица с 4 дырочками: нитка «ныряет» под неё только
прямо, поэтому через неё проходят две нитки, вдоль и поперёк. На пуговице остаётся крестик из двух
цветов. Переходы появляются с 3-й вышивки, и из-за них привычные приёмы «соедини точки» не работают.

**Забег на время:** 90 секунд, сколько вышивок успеешь. Они растут: 4×4 → 5×5 → 6×6 → 7×7 → 8×8.
Вышивка — 5 очков за клетку. Всё поле зашито — ×1,5. **Катушка** — норма времени
(0,9 с на клетку): каждая оставшаяся секунда +5. Когда время вышло, за каждую соединённую пару
недошитой вышивки +5. Есть кнопки «Сначала» и «Пропустить» (без очков).

**Решение есть всегда.** Генератор сначала строит решение: случайный путь через все клетки,
разрезанный на нитки. Потом ставит пуговки на концы. Первая попытка дня — «набор дня» из даты,
одинаковый для всех; каждая следующая попытка — новый набор (дата + номер попытки), поэтому
решения нельзя выучить.

## 2. Сессия и аудитория

- **Сессия:** 90 секунд, время идёт с первого касания. С итогом — около 2 минут.
- **Аудитория:** все участники программы; механика знакома по головоломкам. При первом запуске игра сразу открывает забег, и рука 👆 тянет первую нитку.
- **Телефон:** клетка не меньше 41 px даже на 8×8 (экран 375 px), страница не прокручивается
  и не масштабируется во время игры. У каждого цвета есть значок (круг, звезда, сердце…),
  так что играть можно и тем, кто плохо различает цвета. При сворачивании игра встаёт на паузу.

## 3. Вход и награды

| | |
|---|---|
| Бесплатно | 1 забег в день; 3 дня подряд — 2 в день |
| Платно | 10 пуговок, списываются при первом касании (вышел до него — ничего не списано) |
| Награда за вышивку | 4×4 — разминка, 0 · 5×5 → 1 · 6×6 → 2 · 7×7 → 3 · 8×8 → 4 |
| Всё поле зашито | +1 к любой вышивке |
| Задание дня | одно на всех, проверяется по итогам забега: +5 пуговок |
| Лимит | 60 пуговок в сутки (забеги + задание дня) |
| Траты | 4 вида стежка по 10 пуговок (пунктир, ёлочка, цепочка, крестик), только внешний вид |

**Модель «головоломки дня».** Платят за решённые вышивки: чем больше узор, тем дороже.
Пропущенная и недошитая вышивки не оплачиваются (очки за пары идут только в счёт и рекорд).
Во время забега видно «+N» заработанных пуговок, на итоге — разбивка по размерам, дневной
лимит и подсказка («Зашивай всё поле — было бы ещё +2»).

**Честность наборов.** Размер вышивки и число переходов зависят только от её номера, поэтому
сложность любой попытки одинаковая. Номер попытки дня хранится в `pnt-tries`.

## 4. Экономика

**Допущения.** Игроки 30/40/20/10% (новичок / средний / хороший / сильный).

**Симуляция** в node на настоящих генераторе и `rewardOf()` из игры. Время на вышивку зависит
от числа клеток (1,1 / 0,8 / 0,6 / 0,45 с на клетку, с разбросом), плюс задержка на переходах,
вероятность зашить всё поле (30–85%) и застрять. По 2000 забегов на тип. Генератор
проверен на 6000 вышивках (60 дней × 10 попыток): ошибок нет, размеры и переходы как задумано.

| Игрок | Вышивок за забег | Выплата за вход |
|---|---|---|
| Новичок | ~2,5 | 2,3 |
| Средний | ~3,1 | 3,9 |
| Хороший | ~3,9 | 6,6 |
| Сильный | ~4,8 | 9,8 |

**Средняя выплата ≈ 4,5 пуговки** за вход 10, максимум за забег в симуляции — 14.
Пропуски ничего не дают, поэтому «спам» кнопкой «Пропустить» бесполезен. С оплатой 4×4 = 1
средняя была 5,5, поэтому 4×4 — разминка.

| Сценарий игрока за день | Итог для программы |
|---|---|
| Только бесплатный забег | −4,5 (цена удержания) |
| 1 бесплатный + 1 платный | **+1** |
| 1 бесплатный + 3 платных | **+12** |
| Покупка стежка | **+10** |

**Риски:** модель времени условная — цены по размеру проверить на живых тестерах. Число пар ниток в вышивке одного размера
немного меняется от набора к набору. Очки считаются в браузере, в продакшене нужна проверка
на сервере.

## 5. Как использовали ИИ

Код, генератор головоломок, рисование на canvas, звук, симуляция баланса и этот текст сделаны
вместе с ИИ-ассистентом Claude (Anthropic) в Claude Code. Автор выбрал идею из плана конкурса,
принимал решения по механике и балансу, проверял игру. Стиль — по брендбуку «Пуговок»,
шрифт Onest (SIL OFL).
